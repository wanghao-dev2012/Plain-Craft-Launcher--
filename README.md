# PCL2 修复版

Plain Craft Launcher 2（PCL2）的个人修复版：解锁原版游戏下载、开放联机标签，并附上修复者信息。

## 功能

- **原版游戏下载解锁** —— 恢复「下载 → 原版游戏」的版本列表与安装（26.3 / 快照 / 正式版 / 预览版 / 远古版 / 愚人节版）
- **联机标签开放** —— 顶部栏新增「联机」页，窗口内直接创建 / 加入房间（EasyTier）
- **修复者信息** —— 启动弹窗与下载页提示条，可一键跳转主页

## 使用

1. 备份原来的 `Plain Craft Launcher 2.exe`
2. 把 `Plain Craft Launcher 2.patched.exe` 改名为 `Plain Craft Launcher 2.exe`，覆盖原文件
3. `PclLink.dll` 与 exe 放在同一目录（不要删，联机页占位文本靠它）
4. 启动 → 顶部「联机」→ 创建房间 / 加入房间

## 说明

- 只改动 IL，原版 exe 结构与资源未重建；出问题把备份的 exe 换回来即可
- 联机模块首次使用会自动下载 EasyTier，需要能访问 `easytier.meloong.com`
- 仅供个人使用与学习交流
